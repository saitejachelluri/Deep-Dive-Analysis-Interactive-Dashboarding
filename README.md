# Task 3 - Deep-Dive Analysis & Interactive Dashboarding

## IPL Performance Analytics Dashboard

### Project Overview

This project was developed as part of the ApexPlanet Data Analytics Internship - Task 3: Deep-Dive Analysis & Interactive Dashboarding.

The objective of this project is to perform an in-depth analysis of IPL (Indian Premier League) data and build an interactive Power BI dashboard that provides meaningful insights into team performance, player statistics, venue trends, and match outcomes.

---

## Objectives

* Define and track key performance indicators (KPIs)
* Perform deep-dive analysis on IPL match data
* Identify patterns and trends in team performance
* Analyze the impact of toss decisions on match outcomes
* Explore venue-based insights
* Develop an interactive Power BI dashboard for data-driven decision-making

---

## Tools & Technologies

* Power BI
* Microsoft Excel / CSV
* Data Analytics
* Data Visualization
* Business Intelligence

---

## Dataset

The project uses IPL historical match and delivery-level datasets:

* cleaned_matches.csv
* cleaned_deliveries.csv

---

## Key Performance Indicators (KPIs)

* Total Matches
* Total Runs Scored
* Highest Team Score
* Total Teams

---

## Dashboard Features

### Executive Dashboard

* KPI Overview
* Top Run Scorers
* Top Wicket Takers
* Team Performance Analysis
* Venue Analysis
* Interactive Filters

### Deep-Dive Analysis Dashboard

* Toss Impact Analysis
* Most Successful IPL Teams
* Venue Insights
* Key Business Insights

---

## Key Insights

* Winning the toss has minimal impact on overall match outcomes.
* Mumbai Indians emerged as one of the most successful IPL franchises.
* Certain venues consistently hosted a higher number of IPL matches.
* Team performance and match strategy have a stronger influence on results than toss outcomes.
